# Paper2Speech for Zotero

<img src="addon/content/icons/icon.svg" width="64" height="64" alt="Paper2Speech: a document with a speaker" />

Listen to papers with Apple's built-in voices. Everything runs locally—no API key or cloud service.

**Requires macOS and Zotero 7–10.**

## Install

1. Download **paper-2-speech.xpi** from the [latest release](https://github.com/WeiCheng14159/zotero_paper2speech/releases/latest).
2. In Zotero, open **Tools → Plugins → gear icon → Install Plugin From File…**
3. Select the downloaded XPI.

## Listen

Select a paper with a downloaded PDF, then click **▶ Play** beside the library search box. Click **■ Stop** to end playback.

You can also use the Play/Stop buttons inside an open PDF's toolbar. Starting another paper stops the current reading.

## Voice and speed

Open **Zotero → Settings → Paper2Speech** to choose a voice and reading speed. Changes save automatically and apply the next time you press Play.

## Limitations

- Scanned PDFs need OCR before they can be read aloud.
- Columns, equations, and references may not read naturally.
- Play/Stop only; no pause/resume or word highlighting yet.
